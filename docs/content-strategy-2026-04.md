## 2. 機能×コンテンツ融合案

### 案A: 「BTO vs 自作 シミュレーター」（最優先）

**概要**: 同じスペック要件で「自作した場合の合計」と「BTOで買った場合の価格」を並列表示

**データフロー**:
```
ユーザー入力: 「モンハンワイルズを快適に遊びたい、予算20万」
   ↓
自作構成: RTX 4070 + Ryzen 7 7700 + 32GB = ¥172,260（パーツDB実価格）
BTO構成: サイコム G-Master Velox III = ¥247,060（BTO DB）
         マウス G-Tune HN-C = ¥219,800
   ↓
表示:
  ┌─────────────────────────────────────────────────┐
  │  💰 自作 vs BTO 比較結果                          │
  │                                                   │
  │  🔧 自作する場合: ¥172,260                        │
  │     → 約¥47,000〜75,000 安い！                    │
  │     → ただし組み立て作業が必要                     │
  │     → [パーツリストをAmazonで見る →]               │
  │                                                   │
  │  🏭 BTO で買う場合: ¥219,800〜¥247,060           │
  │     → 組み立て済み・保証1年付き                    │
  │     → [BTOショップで見る →]  (A8.net)             │
  │                                                   │
  │  ⚖️ 差額 ¥47,540 = 組み立て代 + 保証代           │
  └─────────────────────────────────────────────────┘
```

**収益インパクト**: BTO 1台成約 = 報酬率1.5% × ¥220,000 = **¥3,300/件**
（Amazon パーツ = 報酬率2-3% × ¥5,000平均 = ¥100-150/件の20倍以上）

### 指示1: 予算別ランディングページの動的生成

```
app.pyに /build/<budget> ルートを追加。

実装詳細:
1. budget = 10, 15, 20, 25, 30（万円）を受け付ける
2. _load_all_pc_products() で全パーツDBをロード
3. 予算内で最適な構成を自動算出:
   - GPU: 予算の35-40%
   - CPU: 予算の15-20%
   - MB: CPU互換のもので最安
   - RAM: DDR5 16GB or 32GB
   - CASE/PSU/SSD: 残予算で最適
4. 同スペック帯のBTO製品をbto/products.jsonlからマッチング
5. 「自作合計」vs「BTO最安」の比較表を生成
6. Amazon/楽天アフィリエイトリンク + BTO A8.netリンクを生成
7. SEO: title「予算{budget}万円の自作PC構成【2026年最新】| pc-jisaku.com」
   description「予算{budget}万円で組める最強ゲーミングPC。AIが選んだ最適パーツ構成とBTO比較。」
8. 構造化データ: Product schema (aggregate offer)

HTMLテンプレート構造:
- ヒーロー: 「予算{budget}万円で最強のゲーミングPCを組む」
- セクション1: 推奨構成表（パーツ名・価格・Amazon/楽天リンク）

```

### 指示2: チャット結果からの動的コンテンツ生成

```
app.pyの /game/<game_name> ルートに以下を追加:

1. chat_log.jsonlから該当ゲームのチャットデータを集計
2. 以下の「実データ」をゲームページに動的表示:
   - 「このゲームで最も選ばれたGPU: RTX 4060（42%）」
   - 「平均予算: 15.2万円」
   - 「推奨構成で最も多い解像度: FHD 1080p（68%）」
3. チャットデータが10件未満の場合は非表示
4. これにより「テンプレート感」が消え、独自データに基づくコンテンツになる

実装ヘルパー:
def _get_game_chat_stats(game_name):
    """チャットログからゲーム別統計を取得"""
    log_path = os.path.join(..., 'logs', 'chat_log.jsonl')
    stats = {'gpu_counts': {}, 'budgets': [], 'total': 0}
    with open(log_path) as f:
        for line in f:
            entry = json.loads(line)
            if entry.get('game', '').lower() == game_name.lower():
                stats['total'] += 1
                gpu = entry.get('confirmed', {}).get('gpu', {}).get('name', '')
                if gpu:
                    stats['gpu_counts'][gpu] = stats['gpu_counts'].get(gpu, 0) + 1
                if entry.get('budget'):
                    stats['budgets'].append(entry['budget'])
    return stats if stats['total'] >= 10 else None
```
