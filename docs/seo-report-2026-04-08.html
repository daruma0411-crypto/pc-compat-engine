#8 チャット履歴永続化 -- 最重要施策

Before

346件/月のチャットデータが 全て消滅（Redis TTL 1時間で揮発）

  • どのゲームについて質問されているか？ -- 不明
  • ユーザーの予算感は？ -- 不明
  • どのGPUが最も推奨されているか？ -- 不明
  • 回答品質は？ -- 検証不可能

After

全チャットを logs/chat_log.jsonl に永続記録

記録項目:

  • ユーザー質問 / AI応答（各500字）
  • ゲーム名 / 予算 / 用途 / 解像度
  • 確定パーツ（GPU, CPU等）
  • ツール実行ログ / セッションID / ターン数

集計API: /api/chat-analytics

人気ゲーム / 予算分布 / GPU確定ランキング / 時間帯 / 直近質問一覧

「Palworldで最も選ばれたGPU: RTX 4060」のような実データをゲームページに表示 = 独自コンテンツでSEO差別化
