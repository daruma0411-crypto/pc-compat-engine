「エーペックスレジェンズ」が重い・カクつく原因と解決策5選

2026年05月19日 | PC互換チェッカー

エーペックスレジェンズが重い・カクつく原因と解決策5選【2026年GW版】

GWにたっぷり時間ができて「さあエーペックスレジェンズをやり込むぞ！」と意気込んだのに、ゲームが重い・カクつく・FPSが全然出ない……そんな経験、ありませんか？　筆者も去年のGWに久しぶりにエーペックスを起動したら、なぜかカクつきが酷くなっていて、半日ほど原因を追いかけ回した苦い思い出があります。あの時間を返してほしいと今でも思っています（笑）。

この記事では、ベテランのヘルプデスクスタッフが同僚に教えるように、「エーペックスレジェンズが重い・カクつく・FPSが出ない」問題を手順を追って一つずつ解決していきます。初めてPCゲームをやる方でも迷わないよう、できる限り具体的に書きましたので、上から順番に試してみてください。これで8割の人は問題が解決するはずです。

まず最初に：自分のPCを「診断」する

解決策に飛び込む前に、まず「どこが原因なのか」を特定しましょう。ヘルプデスク的に言えば、症状を見ずに薬を出すのは御法度です。まずタスクマネージャーを開いてください。Windowsのキーボードで Ctrl + Shift + Esc を同時押しすると一発で起動します。

タスクマネージャーが開いたら「パフォーマンス」タブをクリックしてください。そこでCPU・メモリ・GPU・ディスクの使用率がリアルタイムで確認できます。エーペックスを起動しながらこの画面を別モニターか別ウィンドウで表示しておくと、どのパーツがボトルネックになっているかが一目でわかります。

  • CPU使用率が90%超え：CPUがボトルネック。解決策1・2を優先
  • メモリ使用率が90%超え：メモリ不足。解決策2・3を優先
  • GPU使用率が90%超えでFPSが低い：GPUが限界。解決策4・5を優先
  • ディスク使用率が100%：ストレージが遅い。解決策3を確認

チェックしましたか？　では原因が絞れたところで、解決策を見ていきましょう。

解決策1：ゲーム内グラフィック設定を最適化する

効果度：★★★★★　　これで5割の人は解決します

エーペックスレジェンズはデフォルト設定のままだと、あなたのPCスペックに対して過剰な負荷がかかっていることがよくあります。まずゲームを起動し、右上の歯車アイコンから「設定」→「ビデオ」を開いてください。

  1. 解像度スケールを「1.0倍（ネイティブ）」のままにしたい気持ちはわかりますが、まず「0.75倍」に下げてみてください。FPSが劇的に改善します
  2. テクスチャストリーミングの予算は「低」に設定。VRAMが少ないGPUでは特に効果大
  3. シャドウディテールを「低」に。影の処理はGPU・CPU双方に重くのしかかります
  4. アンビエントオクルージョンはオフに
  5. FOVが設定可能な場合は90〜100の範囲に。広すぎると描画負荷が増えます
  6. フレームレートの上限を「144fps」や「60fps」に明示的に設定しておく。「無制限」は思わぬ熱暴走の原因になります

エーペックスの推奨スペックは公式から発表されており、一般的にGPUはGeForce GTX 970以上、CPUはCore i5-3570K以上とされていますが、快適な144fps環境を目指すなら現代のミドルレンジGPU以上が実質必要です。この設定見直しだけでも体感FPSは20〜40fps改善するケースが多いです。

解決策2：バックグラウンドアプリを全部「閉じる」

効果度：★★★★☆　　これだけで3割の人が劇的改善を体感します

まずタスクマネージャーを開いてください（まだ開いていない方は Ctrl + Shift + Esc）。「プロセス」タブを見ると、エーペックス以外にもCPUやメモリを食っているアプリが並んでいるはずです。

  1. ブラウザ（ChromeやEdge）は開いているだけでメモリを1〜3GB食います。ゲーム中は必ず閉じる
  2. DiscordはGPUのオーバーレイ機能をオフにするだけでFPSが改善することがあります。Discord設定→「ゲームアクティビティ」→オーバーレイをオフに
  3. アンチウイルスのリアルタイムスキャンはゲームフォルダを除外設定に。Windows Defenderなら「設定→Windowsセキュリティ→除外」から追加できます
  4. Windows Updateが裏で走っている場合があります。タスクマネージャーの「ディスク」使用率が高い場合はほぼこれが犯人です。更新が終わるまで待つか、ゲームセッション後に更新しましょう

筆者の環境では、Chromeを8タブほど開いたままエーペックスを起動していて、メモリ使用率が95%を超えてしまい、カクつきが止まらなかったことがあります。Chromeを閉じた瞬間にFPSが安定し始めたのを今でも覚えています。バカにできない対策です。

解決策3：ドライバーとWindowsを最新に更新する

効果度：★★★☆☆　　特定のバグ持ちドライバーが原因の場合は★★★★★

GPUドライバーが古いまま、あるいは逆に「最新ドライバーがバグ持ち」のケースで深刻なカクつきが発生することがあります。まず現状確認から。

  1. スタートボタンを右クリック→「デバイスマネージャー」を開く
  2. 「ディスプレイアダプター」を展開して、GPUの名前を確認
  3. NVIDIAのGPUなら「NVIDIA GeForce Experience」、AMD（Radeon）なら「AMD Software: Adrenalin Edition」を使うと自動で最適なドライバーを提案してくれます
  4. Windowsのアップデートも忘れずに。スタート→設定→Windows Update→「更新プログラムのチェック」

また、エーペックスレジェンズはEA Appというランチャー経由でプレイします。ゲーム自体のキャッシュが壊れているケースも意外と多いです。EA Appを開き、エーペックスのライブラリページから「修復」を実行してみてください。これだけで謎のカクつきが直ることがあります。

解決策4：PCの「熱暴走」を疑う——サーマルスロットリング対策

効果度：★★★★☆　　長時間プレイで徐々に重くなる人は特必見

「最初の10分は快調なのに、30分経つとカクつき始める」という症状なら、ほぼ間違いなく熱暴走（サーマルスロットリング）が原因です。CPUやGPUが高温になると、自動的に性能を落として自分を守ろうとします。これがサーマルスロットリングです。

まず温度を確認しましょう。無料ツールの「HWiNFO64」や「MSI Afterburner」を使うと、CPU・GPU温度がリアルタイムで監視できます。目安として以下のとおりです。

  • CPUが90℃超え：危険域。CPUクーラーの清掃またはグリスの塗り直しを検討
  • GPUが85℃超え：危険域。ケース内のエアフロー改善かGPUファンの掃除が必要

対処法はシンプルで、まずPCケース内部のホコリを掃除機（エアダスターが理想）で吹き飛ばしてください。筆者はPC自作8年のキャリアの中で、「なぜかゲームが重い」の原因の3割はホコリ詰まりだと体感しています。GW前に大掃除をしていなかった方は、まずここから始めてください。それでも改善しない場合は、CPUクーラーを交換するか、追加のケースファンを取り付けることを検討しましょう。

解決策5：ついにGPUを疑う——スペック不足の場合のアップグレード戦略

効果度：★★★★★　　根本解決ならこれ一択。ただし費用がかかります

上記4つを全部試しても改善しない場合、あるいはタスクマネージャーでGPU使用率が常に100%に張り付いている場合は、GPUのスペック不足が根本原因です。ここは正直に向き合いましょう。エーペックスレジェンズで144fps以上を安定して出したいなら、現世代のミドルレンジGPU以上が実質必要です。

エーペックスレジェンズでフルHD（1920×1080）の144fps環境を目指すなら、GeForce RTX 4070（性能スコア63点、VRAM 12GB、価格.com調べ約55,000円〜）が現実的な最低ラインです。筆者が「RTX 4070はコスパ最強」と信じてやまない理由もここにあります。エーペックスのような競技系FPSは極端な重グラフィックではないため、このクラスのGPUで144fps以上が十分狙えます。

コスパと将来性を両立させたいならRadeon RX 9070（性能スコア70点、VRAM 16GB、価格.com調べ約68,000円〜）も注目です。VRAM 16GBは将来の大型アップデートにも余裕で対応できるメリットがあります。一方、GeForce RTX 5070（性能スコア72点、VRAM 12GB、価格.com調べ約90,000円〜）は最新世代のDLSS4フレーム生成に対応しており、エーペックスでも将来的なドライバー最適化の恩恵を受けやすい点が魅力です。

GPU交換の注意点：落とし穴に気をつけて

  • 電源ユニット（PSU）の容量を必ず確認してください。　RTX 4070なら最低650W、RTX 5080なら850W以上が必要です。筆者は以前、電源をケチって600W電源にRTX 4070 Tiを繋いだら起動不安定になるという苦い経験をしました。電源は絶対にケチってはいけません
  • 中古GPUには要注意。　筆者は一度、某フリマサイトで「美品」と書かれたGPUを購入したら、マイニング用途で酷使された個体を掴まされた経験があります。GPUの中古購入は信頼できるショップか、保証付きのものに限定することを強くおすすめします
  • PCIe補助電源コネクタの形状を確認。　最新のNVIDIA RTX 50シリーズは16ピン（12VHPWR）コネクタが主流です。対応ケーブルが付属しているか事前に確認してください

まとめ：5つの解決策の優先順位

  1. グラフィック設定の最適化（費用ゼロ・効果★★★★★）→まずここから
  2. バックグラウンドアプリを閉じる（費用ゼロ・効果★★★★☆）→次にここ
  3. ドライバー・ゲーム修復（費用ゼロ・効果★★★☆☆）→忘れがちだが重要
  4. 熱暴走対策・清掃（費用ほぼゼロ・効果★★★★☆）→長時間プレイ派は必須
  5. GPUアップグレード（費用5万円〜・効果★★★★★）→根本解決はこれ

この5ステップを順番に試せば、これで8割の人のカクつき問題は解決します。費用ゼロの対策だけでも、体感FPSが30〜50%改善するケースは珍しくありません。それでも解決しない場合は、潔くGPUアップグレードを検討しましょう。
