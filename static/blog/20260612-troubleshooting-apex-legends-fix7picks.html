「エーペックスレジェンズ」が動かない時の対処法7選

2026年06月12日 | PC互換チェッカー

エーペックスレジェンズが起動しない！焦る前にこの7つを試してください

エーペックスレジェンズが起動しない！ロード画面で固まる！クラッシュする！……そんな経験、ありませんか？筆者も過去に全まったく同じ状況で、せっかくの休日をトラブル対応に丸ごと費やしたことがあります。しかも、よりによってフレンドとのスクワッドに誘われていたタイミングで。あの焦りと悔しさは今でも覚えています。

2026年のSteamサマーセール直前というこの時期、新しいゲームをインストールして環境が変わったり、ドライバを更新したりした結果、急にエーペックスレジェンズが動かなくなった、という方も多いはずです。この記事では、筆者が実際に試して効果があった対処法を7つ、初心者の方でも迷わず実行できるよう手順つきでまとめました。上から順番に試していけば、たいていのトラブルは解決できます。落ち着いて、一つずつやっていきましょう。

対処法1：スペック不足の確認

まず最初に確認したいのが、お使いのPCがエーペックスレジェンズの動作要件を満たしているかどうかです。「そんな基本的なこと」と思うかもしれませんが、意外と見落としがちなポイントです。エーペックスレジェンズの一般的な動作要件は以下の通りです。

  • 最低動作環境：CPU Intel Core i3-6300相当以上 / AMD Ryzen 5 1400相当以上、RAM 8GB、GPU NVIDIA GeForce GT 640以上またはAMD Radeon HD 7730以上、ストレージ：56GB以上の空き容量
  • 推奨動作環境：CPU Intel Core i5-3570K相当以上 / AMD Ryzen 5 2600X相当以上、RAM 16GB、GPU NVIDIA GeForce GTX 970以上またはAMD Radeon R9 290以上
  • OS：Windows 10/11 64ビット版

自分のPCスペックを確認するには、キーボードの「Windowsキー＋R」を押して「ファイル名を指定して実行」を開き、「dxdiag」と入力してEnterを押してください。「DirectX診断ツール」が起動し、CPUやRAMの情報が「システム」タブに、GPUの情報が「ディスプレイ」タブに表示されます。

もしスペックが不足している場合は、アップグレードを検討する必要があります。特にGPUのアップグレードが最も効果的です。筆者が現在もっともコスパが優れていると信じてやまないGeForce RTX 4070あたりを搭載したPCなら、エーペックスレジェンズを最高画質で快適に動かすことができます。価格の目安については価格.com調べの情報を後述しますので、そちらも参考にしてください。ここで「スペックは足りている」と確認できれば儲けもん。次のステップへ進みましょう。

対処法2：グラフィックドライバの更新

スペックに問題がなかった場合、次に疑うべきはグラフィックドライバです。これは本当に多い原因で、筆者の経験上、トラブルの3割はドライバの問題で解決します。特に、Windowsアップデートや他のゲームのインストール後に突然エーペックスレジェンズが動かなくなった場合は、ほぼここを疑って間違いありません。

  1. NVIDIAのGPUをお使いの方は「NVIDIA GeForce Experience」を起動してください。インストールされていない場合はNVIDIAの公式サイト（nvidia.com）からダウンロードできます。
  2. GeForce Experienceを開いたら「ドライバー」タブをクリックし、「アップデートの確認」を選択します。
  3. 新しいドライバーが見つかったら「ダウンロード」→「エクスプレスインストール」を選んでインストールします。
  4. AMDのGPUをお使いの方は「AMD Software: Adrenalin Edition」を起動し、同様にドライバーのアップデートを確認してください。AMDの公式サイト（amd.com）からもダウンロード可能です。
  5. インストール完了後は必ずPCを再起動してから、エーペックスレジェンズを起動してみてください。

なお、最新ドライバーで逆に不具合が出ることも稀にあります。その場合は「DDU（Display Driver Uninstaller）」というフリーツールを使って現在のドライバーを完全削除し、一つ前のバージョンのドライバーをNVIDIAまたはAMDの公式サイトから手動でダウンロードしてインストールする方法も有効です。ここで直ればかなり儲けもんです！

対処法3：DirectX / Visual C++の再インストール

グラフィックドライバを更新しても解決しない場合は、エーペックスレジェンズが動作するために必要なランタイムライブラリが壊れているか、不足している可能性があります。特に「DXGI.dll が見つかりません」「vcruntime140.dll が見つかりません」といったエラーメッセージが出ている場合は、この対処法が有効です。

  1. DirectXの更新：Microsoftの公式サイトから「DirectX エンド ユーザー ランタイム Web インストーラー」を検索してダウンロードし、実行してください。最新のDirectXコンポーネントが自動的にインストールされます。
  2. Visual C++ 再頒布可能パッケージの再インストール：Microsoftの公式サイトで「Visual C++ Redistributable」を検索し、2015〜2022年版（x64およびx86の両方）をダウンロードしてインストールしてください。既にインストールされている場合は一度アンインストールしてから再インストールすると効果的です。
  3. インストール後はPCを再起動し、エーペックスレジェンズの起動を試みてください。

これらは完全に無料でできる対処法ですので、手軽に試せます。エラーメッセージが特定のdllファイルを指している場合は、そのファイル名をそのままGoogleで検索すると、対応するランタイムが何かすぐにわかります。地味な作業ですが、ここで直れば大きな儲けもんです。

対処法4：ウイルス対策ソフトの例外設定

意外と盲点なのがこの対処法です。Windows標準の「Windowsセキュリティ（Defender）」や、サードパーティのウイルス対策ソフトが、エーペックスレジェンズの実行ファイルを誤って脅威とみなしてブロックしてしまうことがあります。筆者の環境でも、ある時期からEAのランチャー経由でゲームを起動するとクラッシュが頻発するようになり、原因を調べたらウイルス対策ソフトが怪しい挙動を検知してゲームプロセスを強制終了していた、という経験があります。

  1. Windowsセキュリティの場合：スタートメニューから「Windowsセキュリティ」を開き、「ウイルスと脅威の防止」→「ウイルスと脅威の防止の設定」→「除外の追加または削除」を選択します。
  2. 「除外を追加する」→「フォルダー」を選び、エーペックスレジェンズのインストールフォルダー（デフォルトでは「C:\Program Files (x86)\Origin Games\Apex」または「C:\Program Files\EA Games\Apex Legends」）を追加してください。
  3. EAアプリ（ランチャー）のフォルダーも同様に除外設定することをお勧めします。
  4. サードパーティのウイルス対策ソフトをお使いの場合は、そのソフトの設定画面から「例外」「ホワイトリスト」「除外」などの項目を探し、同様にゲームフォルダーを追加してください。

ウイルス対策ソフトを一時的に無効化してゲームが起動するかどうか試してみることで、これが原因かどうかを切り分けることができます。ただし、無効化中はインターネットブラウジングなど他の操作は控えるようにしましょう。ここで解決したら、セキュリティを戻すことを絶対に忘れずに。

対処法5：管理者権限で実行

エーペックスレジェンズはアンチチートシステム「Easy Anti-Cheat」を採用しており、このシステムが正常に動作するためには管理者権限が必要なことがあります。特に、Windowsのユーザーアカウント制御（UAC）の設定によっては、権限が不足してゲームが起動できないケースがあります。

  1. デスクトップまたはスタートメニューにあるEAアプリ（ランチャー）のアイコンを右クリックします。
  2. 「プロパティ」を選択し、「互換性」タブを開きます。
  3. 「管理者としてこのプログラムを実行する」にチェックを入れ、「OK」をクリックします。
  4. 同様の手順で、エーペックスレジェンズのインストールフォルダー内にある「r5apex.exe」という実行ファイルに対しても管理者権限を設定してください。
  5. 設定後、EAアプリを通常通り起動し、エーペックスレジェンズを起動してみてください。

この設定は一度やってしまえばあとは自動的に管理者権限で起動されるので、手間は最初の一回だけです。シンプルですが効果がある場合も多いので、ぜひ試してみてください。ここで直れば最高に儲けもんです！

対処法6：ファイルの整合性チェック

ゲームのインストールファイルが途中で壊れていたり、一部が欠損していたりすることで、起動できなくなるケースもあります。これはダウンロード中に通信が途切れた場合や、ストレージに問題が起きた場合などに発生しやすいトラブルです。EAアプリにはゲームファイルの整合性を検証・修復する機能が標準搭載されていますので、ぜひ活用してください。

  1. EAアプリ（ランチャー）を起動し、「マイコレクション」からエーペックスレジェンズを探します。
  2. エーペックスレジェンズのタイトル横にある「…（その他のオプション）」ボタンをクリックします。
  3. 「修復」を選択してください。EAアプリが自動的にゲームファイルをスキャンし、壊れているファイルや不足しているファイルを再ダウンロードして修復します。
  4. 修復が完了するまでしばらく待ちます（ファイルの状態によっては10〜30分かかる場合があります）。
  5. 修復完了後、PCを再起動してからゲームを起動してみてください。

エーペックスレジェンズはゲームのデータ容量が大きいため、ストレージへの負荷も相応にあります。もしHDDをお使いの場合は、この機会にSSDへの移行を検討してみてください。読み書き速度が大幅に向上し、ロード時間の短縮やファイル破損のリスク低減にもつながります。価格.com調べでは、Samsung 870 EVO 1TB（SATA SSD）が現在約9,000円前後で購入可能です。コストパフォーマンスの高い選択肢です。

対処法7：セーブデータ・設定ファイルの移動（リセット）

ここまで試してもまだ解決しない場合、エーペックスレジェンズの設定ファイルやローカルキャッシュが破損している可能性があります。これらを一時的に別の場所に移動（バックアップ）してから、ゲームを起動することで設定ファイルが初期化され、問題が解消されることがあります。

  1. エクスプローラーを開き、アドレスバーに「%USERPROFILE%\Saved Games\Respawn\Apex」と入力してEnterを押します。
  2. 「local」「profile」といったフォルダーが表示されます。これらのフォルダー全体を、デスクトップなど別の場所にコピー（バックアップ）してください。
  3. バックアップが完了したら、元の場所にある「local」フォルダーを削除またはフォルダー名を変更（例：「local_bak」）します。
  4. エーペックスレジェンズを起動してみてください。設定ファイルが新しく作成され、初回起動時のような状態で起動します。
  5. もし問題が解決したら、バックアップしたフォルダーから必要な設定ファイルだけを戻すことも可能ですが、問題のあるファイルを持ち込まないよう注意してください。

この方法ではゲーム内のキーバインドや映像設定がリセットされますが、ランクやアカウントデータはサーバー側に保存されているため失われることはありません。安心して試してみてください。これで直れば、まさに「最後の砦を突破した」気分です。ここまで試せば、かなり高い確率で問題は解決しているはずです。
