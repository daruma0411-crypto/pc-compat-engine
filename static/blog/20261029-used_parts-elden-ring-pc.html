中古パーツで組む「エルデンリング」向け格安ゲーミングPC

2026年10月29日 | PC互換チェッカー

新品で組む必要、本当にありますか？

新品で組む必要、本当にありますか？　これ、筆者がPC自作を始めた頃から繰り返し自分に問いかけてきた言葉です。「どうせ買うなら新品を」という気持ちはよくわかります。でも、ちょっと待ってください。ELDEN RING（エルデンリング）のSteam公式推奨スペックをご覧いただくと、推奨GPUはGeForce GTX 1070やRadeon RX VEGA 56、CPUはCore i7-8700KやRyzen 5 3600Xです。2018〜2020年ごろのミドルレンジ帯が推奨ラインということは、裏を返せば、中古市場で十分すぎるほどのパーツが格安で手に入るということ。Metacritic94点という傑作を、わざわざ20万円オーバーの最新構成で遊ぶ必要はどこにもありません。今回は予算5〜8万円の中古パーツ構成でELDEN RINGを快適に遊ぶ方法を、筆者の失敗体験も交えながら徹底解説します。

エルデンリング 公式スペックをおさらい

まず出発点として、ELDEN RINGの公式スペックを整理しておきましょう。Steamに掲載されている要件は以下のとおりです。

項目 最低スペック 推奨スペック
GPU GeForce GTX 1060 3GB / Radeon RX 580 4GB GeForce GTX 1070 8GB / Radeon RX VEGA 56 8GB
CPU Core i5-8400 / Ryzen 3 3300X Core i7-8700K / Ryzen 5 3600X
メモリ 12GB 16GB
ストレージ 60GB 60GB

ポイントは推奨GPUが8GB VRAMの旧世代ミドルレンジという点です。2026年現在の中古市場ではこの世代のGPUはさらに一世代古いものとして扱われており、驚くほど安く手に入ります。ここに格安PC構築の大きなチャンスがあります。

中古GPUの狙い目はどれか？　価格.com調べで検証する

新品価格の相場から逆算して、中古の狙い目を探っていきましょう。価格.com調べ（2026年10月29日時点）で確認できる旧世代GPU新品最安値は以下のとおりです。

GeForce RTX 3060 12GB 81,592円 7製品 △（新品が高すぎ）
GeForce RTX 3070 Ti 8GB 54,800円 10製品 ◎（中古は3万円台も）

新品価格と見比べながら中古相場を探るのが鉄則です。たとえばGeForce RTX 3070 Tiは新品最安が54,800円（価格.com調べ）ですが、中古のヤフオクやメルカリでは動作確認済み品が28,000〜35,000円ほどで流通しています。VRAM 8GBで推奨スペックを大幅に超える性能を持ちながらこの価格帯は破格です。

一方、Radeon RX 6600は新品でも34,989円（価格.com調べ）と既に安価なのに加え、VRAM 8GBで推奨スペックをきちんとカバーします。中古なら18,000〜25,000円の範囲で見つかることも多く、筆者が個人的に「エルデンリング格安PC」を考えるなら真っ先に候補に挙げるGPUです。

なお、GeForce GTX 1660 SUPERの新品最安が36,700円（価格.com調べ）というのは少し不思議な数字です。VRAM 6GBで性能もRX 6600に劣るのに価格差がほぼない。これは在庫整理品の残骸ですので、新品で買う理由はほぼありません。中古で10,000〜15,000円なら話は別ですが、あくまでフレームレートを割り切れる方向けです。

「当たり外れ」体験談：筆者が中古GPUで痛い目を見た話

中古パーツの怖さをリアルに伝えておきたいと思います。筆者も数年前、オークションサイトで「動作確認済み・美品」と書かれた中古GPUを購入したことがあります。届いて取り付けてみると起動はするものの、負荷をかけると数分でブラックアウト。出品者に連絡しても「うちでは動いていた」の一点張りで、結局返品交渉に1週間かかりました。あのときの教訓として、今では以下のチェックリストを必ず守るようにしています。

  • 出品者の評価が100件以上・評価率98%以上であること
  • 「マイニング用途なし」または「使用用途：ゲーム」と明記されているか確認する
  • GPU-Zのスクリーンショットを送付してもらい、センサー値（温度・ファン回転数）が正常かを確認する
  • 納品後72時間以内にFurMarkで30分の負荷テストを実施し、問題があれば即座に返品申請する
  • 可能であれば「らくらくメルカリ便」「ヤフネコパック」など匿名配送＋補償付きの発送方法を指定する

特にマイニング用途での酷使は要注意です。GPUのコアやVRAMが限界まで使われた個体は外見上は問題なくても寿命が極端に短いことがあります。2021〜2022年の仮想通貨ブームで大量に出回った個体が今も中古市場に流れている可能性があるため、RTX 3060やRTX 3070 Tiの中古には特に注意を払ってください。

「ここだけは新品にしろ」「これは中古でOK」の判断基準

中古パーツ構成のコツは、リスクに応じてメリハリをつけることです。すべてを中古にすればいいわけではありません。筆者の経験則と自作コミュニティでの定説をまとめると、以下のように整理できます。

絶対に新品にすべきパーツ

  • 電源ユニット（PSU）：これは絶対に新品を買ってください。筆者も過去に電源をケチって500W中古品を使ったところ、高負荷時に電圧が不安定になり、GPUとSSDを道連れにしてシステムがクラッシュするという最悪の経験をしています。電源の劣化は外見からは判断できませんし、故障した場合に他のパーツを破損させるリスクがあります。80PLUS Bronze以上の認証を受けた新品を必ず選んでください。予算は5,000〜8,000円を確保しましょう。
  • SSD（システムドライブ）：NAND型フラッシュメモリは書き込み回数に寿命があります。中古SSDは残寿命が不明なことが多く、最悪ゲーム中にデータが消えます。250〜500GBのSATASSDなら新品で3,000〜5,000円程度ですので、ここはケチらないでください。
  • CPUグリス（熱伝導グリス）：金額は微々たるものですが、中古CPUを購入した際に前の使用者が塗ったグリスをそのまま使い回すのはNGです。古いグリスは熱伝導率が落ちており、CPUの冷却に悪影響を与えます。必ず新品のグリスに塗り直しましょう。

中古で全く問題ないパーツ

  • CPU：Core i5-8400やRyzen 5 3600Xクラスは中古市場に大量流通しており、価格も安定しています。CPUはマイニングで酷使されることが少なく、物理的な破損がなければ長期間使用可能です。Ryzen 5 3600なら中古で5,000〜8,000円前後で見つかります。
  • メモリ（DDR4）：メモリは比較的故障率が低く、中古品でも動作確認が容易です。16GB（8GB×2枚組）のDDR4-3200が中古3,000〜5,000円で流通していますので積極的に活用しましょう。Memtest86での検証を必ず行ってください（起動USBから無料で実行できます）。
  • PCケース：審美性を気にしなければ中古で十分です。フィルターが清潔であること、ファンマウンターに変形がないことを確認すればOKです。
  • CPUクーラー：ヒートパイプやフィンに物理的な破損がなければ中古でも問題ありません。ただしファンが劣化しているケースがあるため、ファンだけ新品に交換する選択肢も持っておきましょう。

GPUは状態確認必須の「中間」カテゴリ

GPUはマイニング履歴リスクさえクリアできれば中古でOKです。ただし前述の確認事項を怠らないでください。保証付きの中古ショップ（ソフマップやじゃんぱらなど）を利用すれば、オークションよりも安心して購入できます。価格は個人売買より若干高めになりますが、保証期間内に故障が発覚した場合の交換・返金対応があるのは大きなメリットです。

ハロウィンセールと年末商戦を活用するタイミング戦略

2026年10月29日現在、ハロウィンセールが各中古ショップでも展開されています。じゃんぱらやソフマップでは定期的にポイントアップキャンペーンを実施しており、このタイミングを狙って購入するのは賢い選択です。また年末商戦に向けて11〜12月は新品GPUの価格が動きやすい時期でもあります。急ぎでなければ価格.comのアラート機能を設定し、目標価格を下回ったタイミングで購入するのがベストです。筆者はいつも価格.comのアラートを5〜6製品に同時設定して、最初に条件を満たしたものを即購入するスタイルをとっています。

まとめ：エルデンリングを格安中古PCで遊ぶための結論

長くなりましたが、最終的な結論をシンプルにまとめます。ELDEN RINGを格安で遊ぶうえで中古パーツ活用は最善の選択肢です。ただし「電源だけは絶対に新品」「GPUはマイニング履歴に注意してショップ保証付き中古を選ぶ」この2点さえ守れば、大きなトラブルは回避できます。

筆者が今この状況で選ぶとしたら、迷わずRadeon RX 6600中古（約18,000円）＋Ryzen 5 3600中古（約6,000円）のパターンAか、少し背伸びしてGeForce RTX 3070 Ti中古（約30,000円）＋Ryzen 5 5600X中古（約10,000円）のパターンBをおすすめします。どちらも今日2026年10月29日時点でハロウィンセール期間中ですので、中古ショップの在庫を今すぐチェックする価値は十分あります。

具体的には以下の3製品を最優先で価格チェックしてみてください。

  1. Radeon RX 6600（中古・VRAM 8GB）：新品最安34,989円（価格.com調べ）の参考価格を基準に、中古18,000〜22,000円が狙い目です。
  2. GeForce RTX 3070 Ti（中古・VRAM 8GB）：新品最安54,800円（価格.com調べ）の約半値、28,000〜33,000円の中古が優良候補です。
  3. 550〜650W 80PLUS Bronze以上の電源ユニット（新品）：ここだけは価格.comの最安新品を素直に買ってください。6,500〜8,000円の出費を惜しんでシステム全体をリスクにさらさないでください。

記事下のおすすめ購入先から各ショップの最安値をチェックしてみてください。なお、「パーツ選びが難しい」「組み立てに自信がない」という方には、BTO（完成品PC）という選択肢も存在します。マウスコンピューターやパソコン工房などのBTOメーカーではカスタマイズ済みの完成品をオーダーできますので、自作のハードルが高いと感じた方はそちらも検討してみてください。格安中古パーツで組んだPCでの傑作ソウルライクの冒険、ぜひ楽しんでください。
