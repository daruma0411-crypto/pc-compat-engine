「エルデンリング」が動かない時の対処法7選

2026年06月08日 | PC互換チェッカー

エルデンリング、起動しない！その焦り、筆者もよく知っています

「エルデンリング 動かない」「エルデンリング 起動しない」——SteamサマーセールでついにELDEN RINGを購入したのに、いざ起動しようとしたら真っ暗なまま固まる、ロゴ画面でクラッシュする、そもそも起動ボタンを押しても何も始まらない……。この絶望感、筆者も発売直後にまったく同じ状況を経験しました。あの時は深夜2時に格闘して、結局原因はドライバ更新という拍子抜けなオチでしたが、焦っているときは何が正解かまったくわからないものです。

この記事では、ELDEN RINGが動かないときに試すべき対処法を7つ、具体的な手順とともに解説します。初心者の方でも迷わず実行できるよう、スクリーンショットの代わりに文章で丁寧に説明しますので、順番に試してみてください。必ずどこかで光明が見えてきます。

---

その前に：まず公式スペックを確認しよう

ELDEN RINGのSteam掲載の公式動作スペックは以下の通りです。セールで衝動買いした方は、この時点で一度立ち止まって照合してみてください。

項目 最低スペック 推奨スペック
GPU（NVIDIA） GeForce GTX 1060 3GB GeForce GTX 1070 8GB
GPU（AMD） Radeon RX 580 4GB Radeon RX Vega 56 8GB
CPU（Intel） Core i5-8400 Core i7-8700K
CPU（AMD） Ryzen 3 3300X Ryzen 5 3600X
RAM 12GB 16GB
ストレージ 60GB（空き容量） 60GB（空き容量）

Metacriticスコア94点という歴史的傑作ゆえ、「とにかく買ってしまえ」という気持ちはよくわかります。ただ最低スペックを下回っている場合は、後述のスペック対応が必要になります。では対処法を順番に見ていきましょう。

---

対処法1：スペック不足の確認（まずここから）

「エルデンリング 起動しない」トラブルの中で、意外と多いのがスペック不足です。最低スペックを満たしていても、他のアプリが常駐してメモリを食い潰しているケースもあります。

  1. キーボードの「Windowsキー＋R」を押して「ファイル名を指定して実行」を開き、「dxdiag」と入力してEnterを押します。
  2. 「DirectX診断ツール」が起動したら、「システム」タブでCPUとRAMを確認します。「ディスプレイ」タブでGPU名とVRAM容量を確認します。
  3. 上の表と照合し、最低スペックを満たしているか確認してください。
  4. タスクマネージャー（Ctrl＋Shift＋Esc）の「パフォーマンス」タブで、通常時のメモリ使用量が8GB以上になっていないか確認します。

もしGeForce GTX 1060 3GBすら下回っている場合は、残念ながらGPUのアップグレードが必要です。現時点（2026年06月08日）で価格.com調べの相場では、GeForce RTX 4060が約35,800円〜、GeForce RTX 4070が約63,000円〜となっています。筆者が個人的に最もコスパ優秀だと信じているのはRTX 4070ですが、ELDEN RINGを快適に楽しむだけならRTX 4060でも十分すぎるスペックです。スペックが原因の場合、後の手順は飛ばしてパーツ交換を検討してみてください。

ここで「あ、スペックは十分そう」と確認できたなら儲けもんです。次のステップへ進みましょう。

---

対処法2：グラフィックドライバの更新（これで直るケースが一番多い）

筆者の経験上、ELDEN RINGを含むフロム・ソフトウェア作品のトラブルは、グラフィックドライバの更新で半分以上解決します。古いドライバのままだとゲームとの互換性問題が発生し、起動直後にクラッシュすることがあります。

  1. NVIDIA製GPUをお使いの場合：NVIDIA公式サイト（nvidia.com/ja-jp/Download/index.aspx）にアクセスし、「ドライバーのダウンロード」からお使いのGPUのモデルを選択して最新ドライバをダウンロードします。
  2. ダウンロードしたインストーラーを実行し、「カスタムインストール」を選択して「クリーンインストールを実行する」にチェックを入れます。これにより古いドライバの残骸がきれいに消えます。
  3. AMD製GPUをお使いの場合：AMD公式サイト（amd.com/ja/support）から「AMD Software: Adrenalin Edition」をダウンロードしてインストールします。
  4. インストール完了後は必ずPCを再起動してからELDEN RINGを起動してみてください。

「クリーンインストール」という言葉に怖いイメージを持つ方もいますが、これはドライバだけを一度削除して新しく入れ直す操作であり、ゲームデータやOS、他のソフトには一切影響しません。安心して実行してください。ここで直ったら、それだけで今日は大収穫です。

---

対処法3：DirectX・Visual C++の再インストール

ELDEN RINGはDirectX 12を使用しており、それを支えるVisual C++ ランタイムが破損・欠損していると起動できないことがあります。エラーメッセージに「MSVCP」「VCRUNTIME」「d3d12.dll」などの文字が含まれている場合は、この対処法が効果的です。

  1. まずSteamライブラリでELDEN RINGを右クリック→「プロパティ」→「ローカルファイル」→「ローカルコンテンツを参照」でインストールフォルダを開きます。
  2. フォルダ内にある「_CommonRedist」→「vcredist」フォルダを開き、中にある「vc_redist.x64.exe」と「vc_redist.x86.exe」を両方インストールします。
  3. 次にMicrosoft公式サイトからDirectXエンドユーザーランタイムWeb インストーラー（「directx_Jun2010_redist.exe」で検索）をダウンロードしてインストールします。
  4. PC再起動後に起動を試みてください。

この手順は、中古PCを購入した方や、OSを再インストールした直後にELDEN RINGをセットアップした方に特に有効です。必要なランタイムが最初から入っていないケースが珍しくありません。ここも「直ってくれ〜」と念じながら再起動してみてください。

---

対処法4：ウイルス対策ソフトの例外設定

Windows Defenderをはじめとするウイルス対策ソフトが、ELDEN RINGの実行ファイルや「Easy Anti-Cheat（EAC）」を誤検知してブロックするケースがあります。特にセール直後はSteamサーバーが混雑して通常と異なる通信パターンが発生し、誤検知されやすくなることがあります。

  1. Windowsの「スタート」メニューから「Windowsセキュリティ」を開きます。
  2. 「ウイルスと脅威の防止」→「ウイルスと脅威の防止の設定」→「除外の追加または削除」を選択します。
  3. 「除外の追加」→「フォルダー」を選び、ELDEN RINGのインストールフォルダ（通常は「C:\Program Files (x86)\Steam\steamapps\common\ELDEN RING」）を丸ごと追加します。
  4. サードパーティのウイルス対策ソフト（ノートンやマカフィー等）をお使いの場合は、それぞれの管理画面から同様に除外設定を行ってください。
  5. 設定後、PCを再起動してから起動を試みてください。

「ウイルス対策ソフトを緩めるのが怖い」という気持ちもわかりますが、ゲームフォルダ全体を除外するのは多くのゲーマーが日常的に行っている設定です。Steamで購入した正規品のゲームデータは安全ですので、安心して設定してみてください。これで「あっさり起動した」という声も多いです。

---

対処法5：管理者権限で実行

Windowsのユーザーアカウント制御（UAC）が原因で、ELDEN RINGが必要なシステムリソースやフォルダにアクセスできず起動に失敗するケースがあります。解決策は非常にシンプルです。

  1. SteamライブラリでELDEN RINGを右クリック→「プロパティ」→「ローカルファイル」→「ローカルコンテンツを参照」でインストールフォルダを開きます。
  2. フォルダ内の「eldenring.exe」を右クリック→「プロパティ」→「互換性」タブを開きます。
  3. 「管理者としてこのプログラムを実行する」にチェックを入れて「OK」をクリックします。
  4. 同様の手順で「start_protected_game.exe」（Easy Anti-Cheatの実行ファイル）にも管理者権限を付与します。
  5. Steam自体にも同じ設定を行うと効果が高まります。デスクトップのSteamショートカットを右クリック→「プロパティ」→「互換性」→「管理者として実行」にチェックを入れます。

この手順は2分もあれば完了します。特に会社支給のPCやアカウント管理が厳格な環境でゲームをしている場合、劇的に効く対処法です。「そんな簡単なことで？」と思うかもしれませんが、ここで直れば本当に儲けもんです。

---

対処法6：Steamでファイルの整合性チェック（意外と見落とされがち）

Steamのダウンロード中に通信が途切れたり、HDDやSSDに不良セクタがあったりすると、ゲームファイルが一部破損した状態でインストールされてしまうことがあります。特にサマーセール期間中はSteamのサーバーが混み合い、ダウンロードエラーが起きやすくなります。筆者も数年前に某タイトルで同じトラブルにハマり、最終的にファイルの整合性チェックで解決した経験があります。

  1. SteamライブラリでELDEN RINGを右クリック→「プロパティ」を選択します。
  2. 「ローカルファイル」タブを開き、「ゲームファイルの整合性を確認する」ボタンをクリックします。
  3. Steamが自動的にインストール済みファイルと正規ファイルを照合し、破損・欠損しているものがあれば自動でダウンロード・修復します。
  4. ファイル数が多いため、完了まで5〜15分程度かかることがあります。焦らず待ちましょう。
  5. 「1ファイルの検証に失敗しました。再取得されます」などのメッセージが出た場合は正常な動作です。再取得が完了してから起動してみてください。

ELDEN RINGはインストール容量が約60GBと大きめですが、整合性チェック自体はダウンロードを伴わない場合は数分で終わります。「一度アンインストールして再インストールしてみる」という方もいますが、先にこちらを試す方が時間の節約になります。

対処法7：セーブデータの移動・バックアップ（起動後フリーズに効く）

一度は起動できたのに途中でフリーズする、特定のシーンで必ずクラッシュする、という場合はセーブデータの破損が原因のことがあります。また、セーブデータが保存されているフォルダへのアクセス権限が原因で起動失敗するケースも報告されています。

  1. セーブデータは通常「C:\Users\（ユーザー名）\AppData\Roaming\EldenRing」に保存されています。「AppData」フォルダは隠しフォルダのため、エクスプローラーの「表示」→「隠しファイル」を表示する設定にしてからアクセスしてください。
  2. 「EldenRing」フォルダの中にある数字の羅列のフォルダ（Steam IDのフォルダ）をそのままデスクトップなど別の場所にコピーしてバックアップを取ります。
  3. 元のフォルダを右クリック→「プロパティ」→「セキュリティ」タブで、現在のユーザーに「フルコントロール」権限が付与されているか確認します。付与されていなければ「編集」から追加してください。
  4. それでも改善しない場合は、元のセーブデータフォルダを別の場所に移動させ（削除ではなく移動）、ゲームを一度起動して新規セーブデータが作れるか確認します。新規では起動できる場合、元のセーブデータが破損しています。
  5. 破損したセーブデータについては、Steamクラウドのバックアップから復元できる場合があります。Steamの「表示」→「設定」→「クラウド」でクラウドセーブの状態を確認してみてください。

「セーブデータを消したくない」という気持ちはよくわかります。必ずバックアップを取ってから作業してください。また、ここで紹介した手順はファイルを削除するものではなく「移動」や「確認」が中心ですので、データが消えるリスクは最小限です。

それでも解決しない場合：スペック不足なら今がアップグレードの好機

7つの対処法を全て試してなお解決しない場合、根本的なスペック不足の可能性があります。特にGeForce GTX 1060 3GB未満のGPUをお使いの場合や、RAMが8GB以下の場合は、ソフトウェア的な対処では根本的な解決になりません。

2026年06月08日時点（価格.com調べ）で、アップグレードの選択肢として特におすすめできるパーツを以下にご紹介します。

  • GeForce RTX 4060（8GB）：35,800円〜（価格.com調べ）。ELDEN RINGの推奨スペックを大幅に超え、1080p〜1440pで快適なプレイが可能。電力効率も良く、中級ゲーマーの最初の一枚に最適です。
  • GeForce RTX 4070（12GB）：63,000円〜（価格.com調べ）。筆者が現在メインPCに搭載しており、コスパの頂点だと個人的に信じている一枚です。ELDEN RINGはもちろん、今後発売されるタイトルでも長く戦えます。
  • DDR4 16GB（8GB×2）メモリキット：3,800円〜（価格.com調べ）。RAMが12GB未満の場合は16GBへの増設を最優先で検討してください。ELDEN RINGの最低スペックが12GBなだけに、余裕を持った16GBは必須と言えます。

「自作PCのパーツ交換は難しそう」と感じる方には、BTO（完成品）PCという選択肢もあります。RTX 4060を搭載したゲーミングPC完成品が10万円台前半から選べる時代ですので、ドスパラやマウスコンピューターのBTOも検討してみてください。

各パーツの最新最安値は、記事下のおすすめ購入先から各ショップの最安値をチェックしてみてください。価格.comの比較機能を使えば、送料込みの実質価格も一目でわかります。

まとめ：焦らず、一つずつ。ELDEN RINGはその先で待っている

「エルデンリング 動かない」「エルデンリング 起動しない」トラブルの対処法を7つ解説しました。再度まとめると、以下の順番で試すのが最も効率的です。

  1. スペック確認（dxdiagコマンドで即確認）
  2. グラフィックドライバのクリーンインストール（効果大）
  3. DirectX・Visual C++の再インストール
  4. ウイルス対策ソフトの例外設定
  5. 管理者権限での実行
  6. Steamでファイルの整合性チェック
  7. セーブデータの移動・権限確認

7つ全てを試しても解決しない場合や、エラーメッセージの意味がわからない場合は、AI診断チャットで症状を相談してみてください。エラーコードやメッセージをそのままコピペして投げれば、状況に応じた具体的な追加対処法を提案してもらえます。一人で抱え込まず、活用してみてください。

Metacriticスコア94点のこの作品は、起動さえしてしまえば間違いなくその苦労に報いてくれます。サマーセールで手に入れたばかりのELDEN RINGが動き出した瞬間の感動を、ぜひ味わってください。
