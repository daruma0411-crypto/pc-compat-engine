「ドラゴンズドグマ2」のMODを入れるために必要なスペック

2026年05月02日 | PC互換チェッカー

バニラ卒業おめでとう！ドラゴンズドグマ2 MOD導入のスペック完全ガイド

バニラ卒業おめでとうございます！2026年のゴールデンウィーク、せっかく時間ができたのだからとドラゴンズドグマ2のMODに手を出そうとしているあなた、その気持ちよーくわかります。筆者も最初にNexus Modsのページを開いたとき、「これ全部入れたい」と欲張って大変な目に遭いました（その話は後ほど）。MODは沼です。でも最高の沼です。まずは快適に泳ぐために、スペックの話をしっかりしておきましょう。

まず前提：バニラ（無改造）での公式スペックを確認しよう

MOD環境を語る前に、土台となる公式スペックを押さえておく必要があります。Steam掲載の公式スペック（Metacritic: 88点、高評価タイトルです）は以下の通りです。

項目 最低スペック 推奨スペック
GPU GeForce GTX 1070 / Radeon RX 5500 XT（8GB VRAM） GeForce RTX 2080 / Radeon RX 6700
CPU Intel Core i5-10600 / AMD Ryzen 5 3600 Intel Core i7-10700 / AMD Ryzen 5 3600X
RAM 16GB 16GB

注目してほしいのは、最低スペックのGPUがGeForce GTX 1070とRadeon RX 5500 XT（8GB VRAM）であること。「8GB VRAMあれば動く」という表記が公式に明示されている点が重要です。ただし、これはあくまでも「バニラで動く」最低ラインです。MODを入れ始めた瞬間に、この基準はあっさり崩れます。

MODの種類とVRAM消費量の違いを理解しよう

MODには大きく3つの系統があり、それぞれVRAMへの負荷が全然違います。先輩として正直に言っておきますが、この違いを理解せずに「なんでもかんでも入れる」と確実に後悔します。

① ゲームプレイ系MOD（VRAM消費：ほぼ増加なし）

キャラクターの動きやバランスを調整するMOD群です。たとえばポーンの行動AIを改善するもの、アイテムのドロップ率を変えるもの、UIを見やすくカスタマイズするものが該当します。これらはテクスチャやモデルデータを書き換えないため、VRAMへの追加負荷はほぼゼロです。バニラのスペックがそのまま適用されるので、Radeon RX 5500 XTクラスの8GB VRAMでも問題なく動作します。MODデビューはここから始めるのが鉄則です。

② テクスチャ系MOD（VRAM消費：+2GB〜+6GB）

ここからが本番です。テクスチャを高解像度（4K・8K）に差し替えるMODは、見た目の変化が劇的な反面、VRAM使用量が一気に跳ね上がります。2K解像度のテクスチャMODを5〜10個入れただけで、VRAMの消費が2〜4GB増えることは珍しくありません。4Kテクスチャパックを複数組み合わせると+6GBに達することもあります。

筆者も昨年の年末年始に欲張って4Kテクスチャ系MODを一気に10個入れたところ、大型の街エリアで突然フリーズを繰り返す事態になりました。原因は明白で、VRAMが溢れていたのです。当時使っていたGPUのVRAMが足りず、泣く泣く半分以上のMODを無効化した苦い記憶があります。テクスチャ系に手を出すなら最低でも12GB VRAMを強く推奨します。

③ 大型変換系MOD（VRAM消費：+6GB〜+10GB以上）

キャラクターモデルを丸ごと置き換えるMOD、ライティング・シェーダー全体を差し替えるリシェードパック、大規模なマップ改変MODなどが該当します。これらはゲーム本体のリソースを根本から書き換えるため、VRAM消費量がバニラ比で+8GB以上になることも珍しくありません。テクスチャ系MODと組み合わせると、合計VRAM使用量が20GBを超えるケースも実際に報告されています。大型変換系MODを快適に動かすには16GB以上のVRAM、欲を言えば24GBクラスが理想です。

「入れすぎるとこうなる」リアル失敗談

筆者がMOD沼にどっぷりはまった時期の話をします。「テクスチャ4K化」「キャラモデル全置換」「リシェード高画質パック」「環境エフェクト強化」を一気に入れた結果、ロード画面が5分以上かかるようになり、街中では常時15〜20FPSという惨状になりました。しかも原因を特定するために一つずつMODを無効化していく作業が地獄のように面倒で、丸2日を溶かしました。MODは「1つ入れて動作確認、また1つ入れて確認」を繰り返すのが絶対鉄則です。まとめて入れると、何が原因かわからなくなります。これは声を大にして伝えたい先輩の教えです。

この表を見て気づいた人も多いはずです。VRAM 8GBのRX Vega 56が22,800円〜というのは確かに安いですが、テクスチャ系MODに本格的に手を出した瞬間に「もっとVRAMが欲しい」となるのは目に見えています。少し背伸びして12GBのIntel Arc B580（42,545円〜、価格.com調べ）を選んでおく方が、長い目で見てコスパが良いというのが筆者の正直な評価です。

段階的なMOD導入ロードマップ

  1. ステップ1（MOD入門）：ゲームプレイ系・UI改善系MODから始める。VRAMはバニラ基準の8GBで十分。まずNexus Modsのアカウントを作り、Vortex（MODマネージャー）の使い方を覚えることを最優先にしましょう。
  2. ステップ2（中級者）：軽量テクスチャMOD（1K〜2K）を数個追加。このあたりから12GB VRAMが欲しくなります。Intel Arc B580（価格.com調べ: 42,545円〜）はこのゾーンで最もコスパが高い選択肢です。1つMODを入れるごとに必ずゲームを起動して動作確認する習慣をつけましょう。
  3. ステップ3（上級者）：4Kテクスチャパックやリシェードを本格導入。ここでは16GBのVRAMが快適動作の実質的な最低ラインになります。Intel Arc A770（価格.com調べ: 53,799円〜）はこのゾーンをカバーできる現実的な選択肢です。
  4. ステップ4（沼の深淵）：大型変換系MODをフルスタックで運用したいなら24GBクラスが必要。Intel Arc Pro B60（価格.com調べ: 144,280円〜）は価格が跳ね上がりますが、MODを本当にやりきりたいなら選択肢に入ります。ただし正直に言うと、筆者はここまで行く前に一度冷静になることをお勧めします（笑）。

CPU・RAMも忘れずに：VRAM以外のボトルネック

GPUとVRAMばかり語りましたが、大型MODを複数動かす場合はCPUとRAMもボトルネックになります。公式推奨のIntel Core i7-10700やAMD Ryzen 5 3600Xは最低ラインとして確保したうえで、RAMは32GBを用意しておくと精神的に余裕ができます。筆者の環境では16GBのときにMOD多重起動でスワップが頻発していたのが、32GBに増やしてから完全に解消しました。メモリは今や32GBでも価格が下がっているので、ケチる場所ではありません。

どこで買うべきか：注意すべき落とし穴

GPUを中古で買うのは筆者としては非推奨です。以前、筆者が中古GPUを掴まされて「VRAMが実際より少ない偽装品」を引かされた経験があります。表示スペックと実際の動作が異なるケースが中古市場には存在します。MOD用途でVRAMの容量が命綱になる以上、GPU購入は新品を強くお勧めします。価格.comの最安値ランキングで価格帯と在庫状況を確認したうえで、信頼できるショップを選びましょう。

結論：このGWに選ぶべきパーツ

ドラゴンズドグマ2のMODを本格的に楽しむなら、2026年5月現在のおすすめGPUは以下の3点です。

  • Intel Arc B580（VRAM 12GB）：価格.com調べ 42,545円〜。テクスチャ系MODを楽しみたい中級者に最もバランスの取れた選択肢。この価格帯でVRAM 12GBを確保できるのは現時点で強力なコスパです。
  • Intel Arc A770（VRAM 16GB）：価格.com調べ 53,799円〜。4Kテクスチャと中規模変換系MODを組み合わせたい上級者向け。価格差が約1万円ながら16GBのVRAMは将来性も含めて魅力的です。
  • Intel Arc Pro B60（VRAM 24GB）：価格.com調べ 144,280円〜。大型変換系MODをフルに使いこなしたい、いわゆる「MODの沼の住人」向け。価格は高めですが、VRAM 24GBという安心感は格別です。
