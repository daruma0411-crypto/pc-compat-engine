「ファイナルファンタジーVII リバース」が動かない時の対処法7選

ファイナルファンタジーVII リバースが起動しない！焦らず一緒に解決しましょう

ファイナルファンタジーVII リバースが動かない……GWにようやく時間ができて「さあプレイするぞ！」と意気込んだのに、起動しない、クラッシュする、画面が真っ暗のまま……そんな最悪な状況になっていませんか？筆者も昨年末に似たような経験をして、せっかくの休日を1時間半つぶしてしまったことがあります。だからこそ、この記事では「これで直った」「自分もハマったポイント」を包み隠さず7つの対処法にまとめました。焦らず、一つずつ試してみてください。必ずどこかで解決できるはずです。

その前に：最低限確認しておきたいこと

対処法に入る前に、まずゲームの公式スペックを把握しておきましょう。「そもそも動く環境なのか」を知っておくことで、無駄な時間を省けます。Steam掲載の公式スペック（ファイナルファンタジーVII リバース）は以下のとおりです。

最低スペック 推奨スペック
GPU AMD Radeon RX 6600（RX 6600以降が必須）／Intel Arc A580 AMD Radeon RX 6700 XT／NVIDIA GeForce RTX 2070
CPU AMD Ryzen 5 1400／Intel Core i3-8100 AMD Ryzen 5 5600／AMD Ryzen 7 3700X
RAM 16GB 16GB
ストレージ 155GB 155GB

特に注意したいのがGPUです。最低スペックに「RX 6600以降が必須」と明記されており、それ以前の世代（RX 5700やGTX 1080など）では原則として動作保証がありません。「スペック的にはいけるはず」と思い込んでいるケースが意外と多いので、まずここを正直に確認してみましょう。

対処法1：スペック不足の確認

まず「そもそも自分のPCは動く環境なのか」を確認します。Windowsキー＋Rキーで「ファイル名を指定して実行」を開き、dxdiagと入力してEnterを押してください。「DirectX診断ツール」が起動し、「システム」タブでCPU・RAM、「ディスプレイ」タブでGPUの情報が確認できます。

ここで「GPUが最低スペックを下回っている」と判明した場合は、残念ながらパーツのアップグレードが必要です。筆者が価格.com調べ（2026年05月04日時点）で確認したところ、現在コスパが高い選択肢として以下が挙げられます。

  • NVIDIA GeForce RTX 4060（各社製品）：価格.com調べ、最安値約37,800円〜。推奨スペックを余裕でクリアし、将来のタイトルにも対応しやすい一枚です。
  • AMD Radeon RX 7600：価格.com調べ、最安値約29,500円〜。最低スペック（RX 6600）を超えており、1080p環境なら十分快適に動作します。
  • NVIDIA GeForce RTX 4070：価格.com調べ、最安値約62,000円〜。筆者が「コスパ最強」と信じているモデルで、推奨スペックを大きく上回り4K環境でも余裕があります。

なお、スペックは足りているのに動かないという方は、次のステップへどうぞ。ここで直れば儲けもん、ですが焦らず続きを読み進めてください。

対処法2：グラフィックドライバの更新

スペックが問題ないのに起動しない場合、最も多い原因のひとつがグラフィックドライバの古さや破損です。筆者も一度、ドライバを数ヶ月放置していたせいで新しいタイトルが起動すらしなかった経験があります。これは本当によくある話で、ドライバを最新にするだけで一発解決することも珍しくありません。

  1. NVIDIAユーザーは「NVIDIA GeForce Experience」を起動し、「ドライバー」タブから最新版を確認してインストールします。GeForce Experienceが入っていない場合はNVIDIA公式サイトからGPU型番を選んで手動ダウンロードしてください。
  2. AMDユーザーは「AMD Software: Adrenalin Edition」を起動し、「ホーム」画面の更新通知、または「ドライバーと管理」タブから最新ドライバーを適用します。
  3. インストール時は「クリーンインストール」オプションを必ず選択してください。古いドライバのファイルが残ると競合の原因になります。NVIDIAの場合はインストール画面の「カスタム（詳細）」を選ぶとチェックボックスが現れます。
  4. インストール後は必ずPCを再起動し、そのうえでゲームを起動してみましょう。

ここで直れば儲けもん！ドライバ更新は無料でできる対処法なので、絶対に最初のほうに試してほしいステップです。

対処法3：DirectX／Visual C++の再インストール

ファイナルファンタジーVII リバースを含む多くのPCゲームは、「DirectX」と「Visual C++ 再頒布可能パッケージ」というWindowsの追加コンポーネントに依存しています。これらが壊れていたり古かったりすると、起動時にエラーが出るか、エラーも出ずに落ちることがあります。

  1. Steamライブラリでファイナルファンタジーリバースを右クリック→「プロパティ」→「ローカルファイル」→「ローカルファイルを閲覧」を選択します。
  2. インストールフォルダ内の「_CommonRedist」フォルダを開くと、「DirectX」「vcredist」といったサブフォルダがあります。それぞれの中にある「DXSETUP.exe」「vc_redist.x64.exe」などを実行してインストールします。
  3. フォルダが見当たらない場合は、MicrosoftのWebサイトから「DirectX エンド ユーザー ランタイム Web インストーラー」と「最新のVisual C++ 再頒布可能パッケージ」を直接ダウンロードしてインストールしてください。
  4. インストール後はPCを再起動してゲームを試してみましょう。

地味な作業ですが、これで「起動時に英語のエラーダイアログが出て落ちる」というケースはかなりの確率で解決します。ここで直れば儲けもんです。

対処法4：ウイルス対策ソフトの例外設定

「ゲームに関係あるの？」と思われがちですが、ウイルス対策ソフトがゲームのexeファイルを誤検知してブロックしているケースは実は非常に多いです。筆者の環境でもWindows Defenderが特定のゲームファイルを隔離してしまい、起動しないどころかセーブデータが消えかけたという冷や汗ものの体験があります。

  1. Windowsセキュリティ（Windows Defender）を使っている場合：スタートメニューから「Windowsセキュリティ」を開き、「ウイルスと脅威の防止」→「ウイルスと脅威の防止の設定」→「除外の追加または削除」へ進みます。
  2. 「除外の追加」ボタンをクリックし、「フォルダー」を選択してファイナルファンタジーVII リバースのインストールフォルダ（例：C:\Program Files (x86)\Steam\steamapps\common\FINAL FANTASY VII REBIRTH）を丸ごと除外に追加します。
  3. サードパーティ製のウイルス対策ソフト（ノートン、マカフィー、ESET等）を使っている場合も、同様に「除外リスト」や「信頼するプログラム」の設定画面からゲームフォルダを追加してください。各ソフトの設定画面の場所はメーカーのサポートページで確認するのが確実です。
  4. 設定後はPCを再起動し、起動を試みてください。

ここで直れば儲けもん！セキュリティソフトの誤検知は見落としがちな落とし穴です。

対処法5：管理者権限で実行

Windowsの権限設定が邪魔をして、ゲームが必要なファイルやレジストリにアクセスできず起動しないことがあります。特にCドライブ直下やProgram Filesにインストールしている場合は、この問題が起きやすいです。

  1. Steamを完全に終了します（タスクバーのSteamアイコンを右クリック→「Steamを終了」）。
  2. デスクトップまたはスタートメニューのSteamアイコンを右クリックし、「管理者として実行」を選択してSteamを起動します。
  3. Steam経由でゲームを起動してみてください。この方法で直る場合、毎回管理者として実行するのが面倒なら、Steamのショートカットのプロパティ→「互換性」タブ→「管理者としてこのプログラムを実行する」にチェックを入れて恒久的に設定しましょう。
  4. それでも変わらない場合は、ゲーム本体のexeファイル（FFVIIREBIRTHのインストールフォルダ内にある.exeファイル）を直接右クリックして「管理者として実行」を試してみてください。

手順はシンプルなので、ここで直れば儲けもんです。ぜひ試してみてください。

対処法6：ファイルの整合性チェック

ダウンロード中の通信エラーや、HDDの不良セクタ、突然の電源断などによって、ゲームのインストールファイルが壊れている（破損している）ことがあります。筆者も以前、電源ユニットをケチって不安定な環境で使っていた時期に、ダウンロード途中でファイルが壊れて起動できないという事態を何度か経験しました。電源は本当に大事です……それは別の話ですが。Steamにはこの破損を検出・修復してくれる便利な機能があります。

  1. Steamライブラリで「ファイナルファンタジーVII リバース」を右クリックし、「プロパティ」を選択します。
  2. 「ローカルファイル」タブを開き、「ゲームファイルの整合性を確認...」ボタンをクリックします。
  3. Steamが全ファイルをチェックし、壊れているファイルや不足しているファイルを自動的に再ダウンロードします。ファイル数が多い（155GB分）ため、数分〜十数分かかることがあります。完了するまで待ちましょう。
  4. 完了後、「1つのファイルが検証に失敗しました」などのメッセージが出ても心配不要です。Steamが自動修復してくれますので、そのまま再度ゲームを起動してみてください。

ここで直れば儲けもん。ファイル破損は意外と気づかずに放置してしまうケースが多いので、他の対処法を試しても直らない時には必ずこのステップに戻ってきてください。

対処法7：セーブデータの移動

「新しく始めようとしたら起動しない」ではなく「途中からおかしくなった」という場合、セーブデータそのものが破損していてクラッシュの原因になっているケースがあります。また、セーブデータが保存されているフォルダのパーミッション（アクセス権限）の問題で起動できないことも稀にあります。

  1. まずセーブデータの場所を確認します。ファイナルファンタジーVII リバースのセーブデータはデフォルトで以下のパスに保存されています：
    C:\Users\（ユーザー名）\Documents\My Games\FINAL FANTASY VII REBIRTH\
  2. 上記フォルダをエクスプローラーで開き、「SaveData」または「SAVEDATA」フォルダをまるごとデスクトップや外付けドライブなど別の場所にコピー（バックアップ）してください。
  3. バックアップ完了後、元のSaveDataフォルダの名前を「SaveData_backup」などにリネームします。こうすることでゲームがセーブデータを認識できなくなり、新規状態で起動を試みることができます。
  4. ゲームを起動してみてください。正常に起動できた場合、セーブデータの破損が原因です。バックアップしたデータをフォルダに戻してみて、特定のセーブスロットが問題ないか確認しましょう。
  5. 起動できない場合は、リネームしたフォルダを元の名前に戻してから次の対処法を試してください。

ここで直れば儲けもん！セーブデータが無事なまま解決できた時の安堵感は格別です。

スペック不足だった場合のパーツ選びと購入のポイント

対処法1でスペック不足が判明した方向けに、具体的なパーツ選びの話をしておきましょう。ファイナルファンタジーVII リバースは推奨スペックにRTX 2070やRX 6700 XTを要求しており、グラフィックス重視のゲームであることがよくわかります。現行世代のGPUでコスパよく揃えるなら、以下が価格.com調べの現時点（2026年05月04日）のおすすめです。

  • NVIDIA GeForce RTX 4060（MSI、ASUS、玄人志向など各社）：価格.com調べ最安値約37,800円〜。推奨スペックを余裕でクリアし、DLSS3対応でフレームレートを底上げできます。GWセール中のショップも多く、今が買いどきです。
  • NVIDIA GeForce RTX 4070（ASUS、Palit、ZOTACなど）：価格.com調べ最安値約62,000円〜。筆者が「コスパ最強」と長年推しているモデルで、1440p環境でも余裕があり今後の大作タイトルにも安心して対応できます。
  • AMD Radeon RX 7600（Sapphire、PowerColor、XFXなど）：価格.com調べ最安値約29,500円〜。予算を抑えたい方向け。最低スペック（RX 6600）を上回りつつ、1080pでのゲームプレイなら十分快適です。

GPUと一緒にCPUも最低スペック（Ryzen 5 1400・Core i3-8100）付近のものを使っている方は、ボトルネックになる可能性がありますのでCPUのアップグレードも検討してみてください。価格.com調べでAMD Ryzen 5 5600（推奨スペック相当）は現在最安値約13,800円〜と非常に手頃な価格になっています。また、DDR4 16GB（8GB×2枚）メモリキット（G.Skill、Crucialなど）は価格.com調べで最安値約4,500円〜と激安水準になっており、16GB未満の方は即アップグレードをおすすめします。

「自作は不安……」という方には、これらのスペックを標準搭載したBTOパソコン（パソコン工房、G-Tune、フロンティアなど）を完成品として購入する選択肢も十分アリです。記事下のおすすめ購入先から各ショップの最安値をチェックしてみてください。
